## 5. Каталог: ключові поля Product

```ts
{
  slug: string,                  // унікальний ID (kebab-case латиницею + виробник)
  name: string, nameRu: string,  // назва на сайті укр / рос
  manufacturer: string,           // канонічна назва виробника (з _lib_normalize.mjs)
  tier: "econom" | "premium" | "original",
  group: string, groupSlug: string,  // категорія ЗЗР
  activeIngredient: string,       // "Гліфосат, 480 г/л" — формат «Назва, концентрація»
  activeIngredientRu: string,
  packaging: string,              // "5 л" / "10 кг" — фасовка
  rate: string,                   // "1,0 - 2,0 л/га" — норма витрати
  priceVat: number,               // ціна з ПДВ (з прайсу як є)
  priceCash: number,              // готівка = priceWithoutVat × 1.10 ⚠
  unit: "л" | "кг",
  currency: "USD" | "EUR",
  cultures: string[],             // slug-и з lib/cultures.ts
  stage: string[],                // gruntovyi/strakhovyi/desikatsiya/fungicid-t1/insektitsyd/...
  technology?: string[],          // clearfield, clearfield+, express
  priceOnRequest?: boolean,       // плашка «Ціна за запитом»
  image?: string,                 // /products/<slug>.jpg
}
```

⚠ **Формула цін** (зафіксована в `lib/types.ts:calcCash()`): `priceCash = (Ціна без ПДВ із прайсу) × 1.10`. Не копіювати «Ціна без ПДВ» напряму — з'їсть націнку.

## 6. Глосарій агрохімії (короткий — асистент має знати)

### Категорії препаратів (groupSlug)

| Категорія | Що робить | Типові д.р. |
|---|---|---|
| **Гербіцид** | вбиває бур'яни | гліфосат, ізопропіламінна сіль, металохлор, нікосульфурон, римсульфурон, 2,4-Д, дикамба, тифенсульфурон, імазетапір |
| **Фунгіцид** | проти грибкових хвороб (іржа, септоріоз, фомоз, альтернаріоз) | тебуконазол, азоксистробін, ципроконазол, пропіконазол, флутриафол, дифеноконазол, манкоцеб |
| **Інсектицид** | проти комах (попелиця, совка, клоп, трипс, дротяник) | імідаклоприд, лямбда-цигалотрин, тіаметоксам, ацетаміприд, дельтаметрин, хлорпірифос, біфентрин |
| **Протруйник** | передпосівна обробка насіння | тіабендазол, флудиоксоніл, тебуконазол + інсектицидна частина |
| **Десикант** | передзбиральне підсушування | дикват, гліфосат (як десикант), глюфосинат |
| **Регулятор росту** | контроль вилягання, фази | хлормекват-хлорид, тринексапак-етил, мепікват, етефон |
| **Адʼювант** | прилипач/ПАР для покращення робочого розчину | поліоксиетилен, нонилфенол, склеювачі |

### Етапи обробки (stage)

- `gruntovyi` — ґрунтовий гербіцид (до сходів культури)
- `strakhovyi` — страховий гербіцид (по сходах культури і бур'янів)
- `desikatsiya` — передзбиральна десикація
- `fungicid-t1` / `fungicid-t2` — перша і друга фунгіцидна обробка
- `insektitsyd` — інсектицидна обробка (проти конкретного шкідника)

### Норма витрати — типові порядки

**Якщо Сергій каже норму — асистент може порівняти з типовою для класу д.р.:**

| Тип препарату | Типова норма |
|---|---|
| Гербіциди (страхові) | 0,3 – 2,0 л/га |
| Гербіциди (ґрунтові) | 1,5 – 4,0 л/га |
| Фунгіциди | 0,3 – 1,5 л/га |
| Інсектициди (системні) | 0,1 – 0,5 л/га |
| Інсектициди (контактні) | 0,2 – 1,0 л/га |
| Десиканти | 1,5 – 3,0 л/га |
| Протруйники | 0,3 – 1,5 л/т насіння |
| Адʼюванти | 0,1 – 0,3 % робочого розчину (= 0,2 – 0,6 л/200л) |

⚠ **Якщо в прайсі чи у Сергія норма виходить за ці порядки — це сигнал помилки, перевіряти.**

### Технології (technology)

- `clearfield` — гібриди соняшника/кукурудзи з толерантністю до імазамоксу (Pulsar 40)
- `clearfield+` (CL+) — нове покоління, толерантність до Pulsar Flex
- `express` — гібриди соняшника з толерантністю до трибенурон-метилу (Express)
- `optimum-aquamax` — стійкі до посухи (від Pioneer/Corteva)

`sonyashnyk` (соняшник), `kukurudza` (кукурудза), `ozyma-pshenytsa` (озима пшениця), `yari-zernovi` (ярі зернові), `ripak-ozymyi` / `ripak-yaryi`, `soya`, `horoh`, `kartoplya`. Повний список — `lib/cultures.ts`.

## 9. Перевірка якості — типові помилки

- **Дублі товарів** під схожими назвами («Раундап» vs «Раундап Макс») — це РІЗНІ продукти. Не зливати.
- **Категорія неправильна** — постачальник пише «Інсектицид», а за д.р. це Гербіцид. Звіряти з офсайтом виробника.
- **Виробник переплутаний** (наприклад, у прайсі «Регент 20G» під BASF — це справжнє, BASF викупив бренд у Bayer колись; але «Тарга Супер» під Nissan насправді тепер «Тарга Макс» від Самміт-Агро).
- **Цифри в назві важливі.** «Дуал Голд **960**» — концентрація д.р. (S-метолахлор 960 г/л). Без цифри — інший продукт.
- **Latin/cyrillic у прайсі.** «Саммiт-Агро» (з лат `i`) — нормалізатор має звести до «Самміт-Агро». Скрипт `_lib_normalize.mjs` це робить.
