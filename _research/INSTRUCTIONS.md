# Інструкція для ресерч-агента

> Завдання: для кожного SKU зі списку знайти **діючу речовину** і **норму витрати**.
> Заповнюємо `activeIngredient` (укр), `activeIngredientRu` (рос), `rate` для нових 578 оригіналів у каталозі agrosnab-pivden.com.

## Що повернути

Файл `_research/<producer-slug>.json` зі структурою:

```json
{
  "producer": "Сингента",
  "researchedAt": "2026-05-06T...",
  "items": [
    {
      "slug": "duial-hold-960-synhenta",
      "name": "Дуал Голд 960",
      "activeIngredient": "S-метолахлор, 960 г/л",
      "activeIngredientRu": "S-метолахлор, 960 г/л",
      "rate": "1,0 - 1,6 л/га",
      "source": "https://www.syngenta.ua/product/crop-protection/herbicides/dual-gold-960-ec"
    },
    {
      "slug": "...",
      "name": "...",
      "activeIngredient": null,
      "activeIngredientRu": null,
      "rate": null,
      "source": null,
      "skipReason": "Не знайдено на офсайті виробника, ні в ДПСС, ні в дилерських каталогах"
    }
  ]
}
```

## Формат полів

- **`activeIngredient`** (укр) — як на нашому сайті: `"Імазамокс, 25 г/л"` або з кількома компонентами `"Імазамокс, 25 г/л; імазапір, 17,5 г/л"`. Назва д.р. з великої букви, кома, пробіл, концентрація.
- **`activeIngredientRu`** (рос) — те саме, але кирилицею російською: `"Имазамокс, 25 г/л"`.
- **`rate`** — норма витрати на гектар: `"1,0 - 1,6 л/га"` або `"0,3 - 0,5 кг/т"` (для протруйників). Тільки число + одиниця, без зайвого тексту. Якщо в реєстрі є кілька діапазонів для різних культур — взяти **найширший** діапазон (від мінімального до максимального).
- **`source`** — URL сторінки, з якої взяті дані. Обов'язково.

## Правила

- **Не вгадувати.** Якщо не знайдено в трьох категоріях джерел — ставити `null` з `skipReason`.
- **Не плутати продукти.** Якщо назва товару збігається, але виробник інший — це інший продукт. Перевіряй виробника на офсайті.
- **Серед похожих назв** (наприклад «Карамба» vs «Карамба Турбо») — точно той, що в нашому списку. Якщо в прайсі скорочена назва, шукай повну.
- **Норма витрати** — береться для **зернових/польових культур** (соняшник, пшениця, кукурудза, соя, ріпак). Не для дрібних/специфічних культур якщо є вибір.
- **Концентрація** іноді написана у назві (наприклад «Дуал Голд 960» — 960 г/л). Підтверджуй на офсайті.

## Швидкість і обсяг

- На один SKU — у середньому 1-3 хв (відкрити сторінку виробника, скопіювати дані, перевірити).
- Якщо за 5 хв на один SKU нічого не знайшов — `null` + skipReason, рухайся далі.
- Звіт зберігати **інкрементально** після кожних 10 SKU, щоб не втратити прогрес при обриві.

## Після завершення

Створи коротке зведення в кінці звіту:
- Скільки SKU оброблено
- Скільки знайдено повністю (д.р. + норма)
- Скільки лише д.р. (без норми)
- Скільки повністю не знайдено
- Топ-3 проблемних SKU (які не вдалось знайти)
